สำรองข้อมูลร้าน

ดาวน์โหลดไฟล์สำรองจาก Supabase โดยตรงจากบัญชี Admin เก็บข้อมูลสินค้า ออเดอร์ ต้นทุน และลิงก์รูปเสริมครบ โดยไม่ส่งไฟล์ไปเซิร์ฟเวอร์สำรองภายนอก

—สินค้า
—ออเดอร์
—ต้นทุน
—รูปเสริม

ไฟล์สำรองอาจมีข้อมูลลูกค้าและต้นทุน ห้ามเผยแพร่ใน GitHub สาธารณะหรือส่งต่อบุคคลอื่น ไฟล์นี้เก็บลิงก์รูปแต่ไม่รวมไฟล์ภาพจริงใน Supabase Storage

สำรองข้อมูลภายในอัตโนมัติ: ตั้งเวลา 03:00 น. (ประเทศไทย) ทุกวันใน Supabase และเก็บสำเนาภายในย้อนหลัง 30 วัน ทั้งนี้เป็นสำเนาในฐานข้อมูลเดียวกัน ไม่ใช่สำรองข้อมูลนอกระบบ ควรดาวน์โหลด JSON เก็บไว้เป็นสำเนาภายนอกด้วย

ตรวจไฟล์สำรองและกู้คืนข้อมูลที่หายไป

เลือกไฟล์ JSON ที่ดาวน์โหลดจากหน้านี้เพื่อเปรียบเทียบกับฐานข้อมูลจริง โดยยังไม่เปลี่ยนอะไร

ยังไม่ได้เลือกไฟล์

ระบบกู้คืนเฉพาะสินค้า ต้นทุน และข้อมูลรูปเสริมที่ขาด ไม่เขียนทับรายการเดิมและไม่กู้คืนออเดอร์เก่าอัตโนมัติ เพราะอาจทำให้สถานะขายและสต๊อกผิดพลาด การกู้คืนออเดอร์หรือทั้งฐานข้อมูลต้องใช้การสำรอง/กู้คืนของ Supabase โดยผู้ดูแลฐานข้อมูล เมื่อเกิดเหตุจำเป็น

ข้อควรทราบ

การกู้คืนแบบเพิ่มรายการอาจสำเร็จเพียงบางรายการหากเครือข่ายขัดข้อง แต่จะไม่เขียนทับข้อมูลเดิม หากต้องการกู้คืนย้อนหลังทั้งระบบให้ใช้ระบบสำรองฐานข้อมูลของ Supabase ตามแพ็กเกจและทดสอบในโปรเจกต์แยกก่อน
