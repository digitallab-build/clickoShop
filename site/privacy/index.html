CLICKO / PRIVACY

นโยบายความเป็นส่วนตัว

Clicko จัดเก็บข้อมูลบัญชีสมาชิกที่ผู้ใช้กรอก เช่น ชื่อ นามสกุล วันเกิด ที่อยู่ เบอร์โทรศัพท์ และอีเมล เพื่อจัดการบัญชีและติดต่อเกี่ยวกับการใช้บริการ ข้อมูลบัญชีจัดเก็บผ่าน Supabase และจำกัดการเข้าถึงตามสิทธิ์ของบัญชี

เมื่อส่งคำขอรับซื้อหรือเทิร์น เว็บไซต์จะจัดเก็บชื่อ นามสกุล ชื่อ Facebook เบอร์โทร รายละเอียดสินค้า และสภาพสินค้าใน Supabase เพื่อระบุคำขอ ติดต่อกลับ และประเมินราคา พนักงานที่ได้รับอนุญาตใช้หน้า dashboard ของร้านเพื่อตรวจสอบข้อมูล รูปที่แนบไว้กับคำขอเก่าจะอยู่ในพื้นที่ส่วนตัวของร้าน ส่วนฟอร์มปัจจุบันไม่รับอัปโหลดรูป

เว็บไซต์ไม่ขอและไม่จัดเก็บเลขบัตรประชาชนหรือ Facebook token การส่งลูกค้าไป Messenger เป็นเพียงการเปิดช่องทางให้ลูกค้าติดต่อผู้ขาย โดยเว็บไซต์ไม่ส่งข้อความในนามลูกค้า

หากต้องการแก้ไขหรือลบข้อมูล หรือสอบถามเรื่องความเป็นส่วนตัว กรุณา ติดต่อ Clicko
