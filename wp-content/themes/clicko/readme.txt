Clicko Theme
============

Responsive WordPress catalog theme for Clicko Gaming Gear & PC Parts.

Requires WordPress 6.6+ and PHP 8.0+. Install WooCommerce for the product catalog.

Seller editing:
- Products, SKUs, prices, variations, categories and attributes: WooCommerce Products.
- Home hero text, accent color, tagline and top bar: Appearance > Customize > Clicko homepage.
- Logo and site identity: Appearance > Customize > Site Identity.
- Pages and home page body: Pages > All Pages.
- Navigation: Appearance > Menus.
- Seller and Page links: Clicko > Settings in the dashboard (Clicko Catalog Tools plugin).

The theme displays public products as a catalog. It does not render product purchase checkout controls.
